# Changelog

All notable changes to the Online Concert Ticketing System will be documented in this file.

## [1.0.0] - 2026-08-28

### Added
- Initial Release of Full-Stack Online Concert Ticketing System
- Customer Portal with Hero Banner, Concert Cards, and Floating Promotion Popup
- Admin Login Modal with Quick Autofill Admin Demo button
- Admin Management System with 13-section sidebar, live statistic metrics, and security monitoring
- Real-Time Seat Synchronization via Socket.IO
- Atomic Double Booking Prevention with MySQL `SELECT FOR UPDATE` transactions
- 10-Minute Seat Hold Reservation Timer & Background Worker
- AI Face Scan & Liveness Verification Simulation
- OTP Verification Simulation
- Simulated Payment Gateway (PromptPay QR, Credit Card, Bank Transfer)
- E-Ticket Generation with Anti-Fraud QR Code, Barcode, and Printable View
- Anti-Bot Rate Limiting, Headless Bot Detection & IP Blocklist Management
- Audit Logging & Login History Tracking
- Server-side Excel (.xlsx) Reports Export
- Vitest Unit/Integration Tests & Concurrency Double Booking Test
- Playwright E2E Tests
- Docker & Docker Compose setup
- GitHub Actions CI/CD Workflows
- Full Technical Documentation under `/docs/`
