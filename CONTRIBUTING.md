# Contributing Guidelines

1. Create a feature branch from `develop`: `git checkout -b feature/your-feature`
2. Follow Conventional Commits format (`feat:`, `fix:`, `docs:`, `test:`, `security:`)
3. Ensure all tests and linting pass before submitting a Pull Request:
   `npm run lint && npm run tsc && npm run test`
4. Pull Requests require passing CI quality gates before merge.
