## 1. ภาพรวมระบบ (System Overview)

**ระบบจำหน่ายตั๋วคอนเสิร์ตออนไลน์ (Concert Ticketing System)** พัฒนาขึ้นด้วยเทคโนโลยีเว็บแอปพลิเคชันยุคใหม่ (Next.js 14 App Router, Full-stack REST API, Socket.IO Real-time Synchronization, Prisma ORM, SQLite/MySQL) รองรับการใช้งานแบบ Responsive บนคอมพิวเตอร์ แท็บเล็ต และสมาร์ตโฟน 

### 🌟 ฟีเจอร์หลักเด่นของระบบ:
- 🛡️ **Anti-Bot Security (6 ชั้น)**: ระบบสแกนและบล็อกบอทกว้านซื้อตั๋วอัตโนมัติ (AI Scalper Defense 5s Inspection + Rate Limiting 500 TPS)
- 👤 **AI Face Scan Liveness & SMS OTP (2-Step Verification)**: สมัครสมาชิกใหม่ต้องสแกนใบหน้าจริง (AI Liveness Simulation) และยืนยันรหัส SMS OTP (`123456`)
- 🎫 **Interactive Real-time Seat Map**: ผังเลือกที่นั่งโต้ตอบ อัปเดตสถานะแบบ Real-time ผ่าน Socket.IO พร้อมระบบล็อคที่นั่งชั่วคราว 10 นาที (Reservation Countdown)
- 🎟️ **My E-Tickets Collection**: บัตรคอนเสิร์ต E-Ticket พร้อม QR Code, Barcode และฟังก์ชันดาวน์โหลด/พิมพ์ตั๋วออกเป็นไฟล์ PDF
- 🎛️ **Admin Full Control Dashboard (13 เมนู)**: ระบบบริหารจัดการฝั่ง Admin ครบวงจร ทั้งการจัดการคอนเสิร์ต, โซน, ที่นั่ง, ผู้ใช้งาน & Roles (RBAC), โปรโมชั่นส่วนลด, การส่งออกรายงาน Excel (XLSX) และ AI Bot Simulator

## 3. คู่มือสำหรับลูกค้าทั่วไป (Customer Portal Manual)

### 3.1 การเข้าสู่ระบบและการสมัครสมาชิกใหม่ (2-Step Verification)
1. กดปุ่ม **"เข้าสู่ระบบ"** หรือ **"สมัครสมาชิก"** บนแถบ Navbar ด้านบน
2. เลือกแท็บการทำงาน:
   - **แท็บ 1: เข้าสู่ระบบสมาชิก**: กรอกอีเมลและรหัสผ่าน หรือกด *"ใส่รหัส Customer Demo"* แล้วกด *"เข้าสู่ระบบสมาชิก"*
   - **แท็บ 2: สมัครสมาชิกใหม่**:
     - กรอกข้อมูล ชื่อ, นามสกุล, อีเมล, เบอร์โทรศัพท์, สัญชาติ และรหัสผ่าน
     - กดปุ่ม **"สมัครสมาชิกใหม่"** ➔ ระบบจะเปิดป๊อปอัป **AI Face Scan (Liveness Simulation)** ➔ กด *"เริ่มสแกน Liveness"* จนขึ้นป้ายสีเขียวสำเร็จ
     - ระบบจะเปิดป๊อปอัป **SMS OTP Verification** ➔ กรอกรหัสทดสอบ **`123456`** ➔ กด *"ยืนยันรหัส OTP"*
     - บัญชีสมาชิกจะถูกสร้างพร้อมทำการยืนยันตัวตนสำเร็จและเข้าสู่ระบบให้อัตโนมัติ!

### 3.2 การเลือกคอนเสิร์ตและตรวจสิทธิ์ AI Verification (5 วินาที)
1. ในหน้าแรก คลิกเลือกคอนเสิร์ตที่ต้องการ แล้วกดปุ่ม **"เลือกที่นั่ง"**
2. ระบบจะแสดงป๊อปอัป **AI Scalper Bot Inspection Modal** สแกนประมวลผลความปลอดภัยและสิทธิ์การเข้าซื้อตั๋วเป็นเวลา 5 วินาที
3. เมื่อประมวลผลสำเร็จจะขึ้นไอคอนสีเขียว **"ผ่านการตรวจสอบสิทธิ์แล้ว (AI Verified)"** และพากลับสู่หน้าผังเลือกที่นั่งอัตโนมัติภายใน 5 วินาที

### 3.3 ผังเลือกที่นั่งแบบเรียลไทม์และการล็อคที่นั่ง 10 นาที
1. คลิกเลือกที่นั่งบนผังโต้ตอบ (เลือกได้สูงสุด 4 ที่นั่ง/รายการจอง):
   - 🟢 **สีเขียว**: ที่นั่งว่าง (Available)
   - 🟡 **สีเหลือง**: ที่นั่งติดล็อคชั่วคราว 10 นาที (Held)
   - 🔴 **สีแดง**: ที่นั่งขายแล้ว (Sold Out)
2. กดปุ่ม **"ดำเนินการจองที่นั่ง (Lock 10 นาที)"**
3. ตัวนับถอยหลัง 10 นาทีจะเริ่มทำงาน หากชำระเงินไม่ทันภายใน 10 นาที ที่นั่งจะถูกคืนสู่ระบบอัตโนมัติ

### 3.4 การชำระเงินผ่าน PromptPay QR และการใช้โค้ดส่วนลด
1. ในหน้าชำระเงิน จะแสดง PromptPay QR Code ประจำรายการจอง
2. คัดลอกรหัสคูปองส่วนลดจากหน้า **"โปรโมชั่น"** (เช่น `SUMMER10`) นำมากรอกเพื่อรับส่วนลด
3. กดปุ่ม **"จำลองชำระเงินสำเร็จ (Simulating Payment)"**

### 3.5 การรับ E-Ticket และการสแกนเข้างาน (My Tickets)
1. คลิกเมนู **"ตั๋วของฉัน"** บน Navbar ด้านบน (หรือไปที่ `/my-tickets`)
2. ระบบจะแสดงตั๋วคอนเสิร์ตที่คุณชำระเงินสำเร็จทั้งหมด
3. กดปุ่ม **"ดู E-Ticket & สแกนเข้างาน"** เพื่อแสดงบัตรฉบับเต็ม พร้อม QR Code, Barcode และปุ่มดาวน์โหลด/พิมพ์เป็น PDF

## 4. คู่มือสำหรับผู้ดูแลระบบ (Admin Panel Manual - 13 เมนู)

เข้าสู่ระบบด้วยบัญชี Admin (`admin@concert.com` / `Admin@123456`) แล้วกดปุ่ม **"Admin Login"** เพื่อเข้าสู่ Admin Panel (`/admin`)

### 4.1 แดชบอร์ดสรุปยอดภาพรวม (Admin Overview) — `/admin`
- สรุปยอดขายรวม, ปริมาณคำขอ (TPS), สถิติจำนวนตั๋วที่จำหน่าย และบันทึกเหตุการณ์ความปลอดภัย Anti-Bot แบบเรียลไทม์

### 4.2 จัดการผู้ใช้งาน & สิทธิ์ RBAC (User & Role Management) — `/admin/users`
- **ค้นหาและกรองผู้ใช้งาน**: ตามชื่อ, อีเมล หรือสถานะ
- **เพิ่ม / แก้ไขผู้ใช้งาน**: แก้ไขชื่อ, อีเมล, เบอร์โทรศัพท์ และเปลี่ยนสิทธิ์ Role (`Customer`, `Admin`, `Super Admin`) ได้ทันที
- **สลับสถานะบล็อกบัญชี**: กดสลับสวิตช์เปิด-ปิดเพื่อระงับใช้งาน (`BLOCKED`) หรือคืนสิทธิ์ (`ACTIVE`)
- *การเปลี่ยนแปลงจะถูกซิงก์ Socket.IO เรียลไทม์ทั้งระบบทันที*

### 4.3 จัดการคอนเสิร์ต (Concerts Management) — `/admin/concerts`
- **เพิ่มคอนเสิร์ตใหม่**: สั่งสร้างคอนเสิร์ต กำหนดชื่อ, ศิลปิน, สถานที่, วันเวลา, รูปโปสเตอร์ และสถานะ (`ON_SALE` / `UPCOMING` / `SOLD_OUT`)
- **แก้ไขและลบ**: สามารถแก้ไขรายละเอียดหรือลบคอนเสิร์ตออกจากระบบได้ทันที

### 4.4 จัดการโซนและที่นั่ง (Event Zones & Seats) — `/admin/zones`
- **เพิ่มโซน**: กำหนดชื่อโซน, ราคาตั๋ว, รูปแบบแถวและจำนวนที่นั่งต่อแถว (ระบบจะสร้างที่นั่งเดี่ยวในฐานข้อมูลให้อัตโนมัติ)
- **ปรับสถานะที่นั่งรายบุคคล**: สามารถคลิกปรับสถานะที่นั่งเดี่ยวเป็น **ว่าง (Available)**, **งดจำหน่าย (Blocked)** หรือ **ขายแล้ว (Sold)**

### 4.5 ออกแบบผัง Visual Editor (Seat Map Designer) — `/admin/visual-editor`
- เครื่องมือออกแบบผังแบบ **Drag & Drop Interactive Canvas** สามารถลากย้ายตำแหน่งเวที, ซุ้ม VIP และโซนต่างๆ ได้อิสระพร้อมบันทึกพิกัด

### 4.6 จัดการโปรโมชั่นและคูปองส่วนลด (Promotions) — `/admin/promotions`
- **สร้างโค้ดส่วนลด**: กำหนดรหัสโค้ด (เช่น `SUMMER10`), ประเภทส่วนลด (% หรือ บาท), มูลค่าส่วนลด และวันหมดอายุ
- **สลับสถานะเปิด-ปิดใช้งาน**: กดสวิตช์เปิด/ปิดใช้งานคูปองได้ทันที โดยข้อมูลจะซิงก์ไปยังฝั่งลูกค้าเรียลไทม์

### 4.7 จัดการรายการจอง & คืนตั๋ว (Bookings & Refunds) — `/admin/bookings`
- ตรวจสอบรายการจองตั๋วทั้งหมดในระบบ พร้อมปุ่ม **"Export Bookings XLSX"** สำหรับดาวน์โหลดรายงานออกเป็นไฟล์ Excel

### 4.8 ระบบจำลอง AI ตรวจสอบบอท (AI Bot Simulator) — `/admin/ai-monitoring`
- แผงทดสอบยิงคำขอจำลอง:
  - ปุ่ม **"🤖 จำลองยิงแบบ Bot Attack"**: ยิงคำขอความถี่สูง 500 TPS เพื่อทดสอบระบบตัดบล็อก IP อัตโนมัติ (429 Too Many Requests)
  - ปุ่ม **"👤 จำลองยิงแบบ คนจริง"**: ยิงคำขอปกติจากผู้ใช้ผ่าน Liveness Scan (200 OK)

### 4.9 จัดการสิทธิ์ RBAC Matrix (RBAC Control Matrix) — `/admin/rbac`
- ตารางกำหนดเมทริกซ์สิทธิ์การเข้าถึงแต่ละโมดูลของ Role ต่างๆ

### 4.10 ประวัติบันทึกการทำงาน (Audit Logs) — `/admin/audit-logs`
- ตรวจสอบประวัติการทำงานย้อนหลังของ Admin พร้อมปุ่มดาวน์โหลดรายงาน Excel (Audit Logs XLSX)

## 5. คู่มือการติดตั้งและการ Deploy (Setup & Deployment)

### 5.1 การรันระบบในเครื่อง local (Local Development)
```bash
# 1. ติดตั้ง dependencies
npm install

# 2. ทำการ Migrate ฐานข้อมูล SQLite & Seed ข้อมูลเริ่มต้น
npx prisma db push
npm run db:seed

# 3. รัน Next.js Dev Server
npm run dev
```

### 5.2 การ Deploy ขึ้น Railway.app (Dockerfile Builder)
1. นำซอร์สโค้ดดันขึ้น GitHub Repository
2. ใน **Railway.app** กด **"+ New Project"** ➔ เลือก **"Deploy from GitHub repo"**
3. เลือก **Dockerfile Builder** (ระบุใน `railway.json`)
4. เพิ่ม **Variables**:
   - `DATABASE_URL` = `file:/app/prisma/dev.db`
   - `NODE_ENV` = `production`
5. เพิ่ม **Volume** มาร์เก็ต Mount Path เป็น `/app/prisma` (รักษาข้อมูล SQLite ไม่ให้หายเมื่อ Redeploy)
6. กด **Generate Domain** เพื่อรับ URL เว็บไซต์พร้อมใช้งานทันที!
