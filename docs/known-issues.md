# Known Issues & Future Enhancements

## Known Issues
- Camera video preview in AI Face Scan requires HTTPS or `localhost` context due to browser security restrictions (`getUserMedia`).
- Demo OTP code is fixed to `123456` via environment variable `DEMO_OTP_CODE`.

## Future Improvements
- Integration with external SMS Gateway (e.g. Twilio / Thailand SMS Provider).
- True Biometric Face recognition API integration (e.g. AWS Rekognition).
- Live Bank Payment Gateway integration (e.g. Omise / Stripe / Ksher).
